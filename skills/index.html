Perguntas

Antes de baixar.

O essencial sobre licença, instalação e o que vem em cada pacote.

Baixar grátis
É grátis de verdade?

Sim. As 370 skills grátis baixam direto, sem cadastro e sem cartão: uma por uma, por categoria ou todas de uma vez.

De onde vêm as skills grátis?

De 24 repositórios abertos, com licença MIT, Apache-2.0 ou ISC. Cada pasta leva o arquivo LICENSE do autor, e o NOTICES.md traz a origem e a licença de todas.

Como instalo?

Descompacte o arquivo em ~/.claude/skills/ e reinicie o Claude Code. No Windows, extraia para %USERPROFILE%\.claude\skills.

Posso baixar só uma skill?

Pode. Cada skill tem o próprio arquivo, e cada categoria também. Você não precisa levar o pacote inteiro.

O que tem no pacote autoral?

9 skills criadas pela VisionX, listadas acima, com método, checklist e verificadores prontos para rodar no seu projeto.

Posso usar em trabalho comercial?

As skills grátis seguem a licença de cada autor (MIT, Apache-2.0 e ISC permitem uso comercial mantendo o aviso). As autorais são de uso licenciado, com direitos reservados; os termos vêm no AVISO-AUTORAL.txt de cada uma.

Preciso de chave ou ferramenta externa?

Algumas skills dependem de ferramentas ou chaves que você mesmo precisa ter. A descrição de cada skill diz o que ela usa.

Funciona só no Claude Code?

As skills são pastas com um arquivo SKILL.md, no formato que o Claude Code lê. Em outras ferramentas, o conteúdo serve de referência, mas a instalação acima é a do Claude Code.
